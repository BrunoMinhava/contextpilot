# FAQ

**Does this save subscription quota?** Not established. Character reduction is not token billing or subscription accounting.

**Is it better than Headroom?** No controlled agent comparison has been run. No superiority claim is supported.

**Is it lossless?** Originals are retained until expiry/eviction. A smaller displayed representation can still affect model behavior. Diagnostics and unknown content are preserved conservatively.

**Is data uploaded?** ContextPilot has no outbound network code. Your MCP client may send returned content to its configured model provider.

**Are originals encrypted?** No. Cache files are plaintext SQLite protected by local directory/file permissions on POSIX. Use OS disk encryption and a trusted account. Windows ACL validation remains outstanding.

**Does it change my model?** No.
